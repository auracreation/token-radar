Token Radar ranks pre-token DeFi protocols by implied launch value and shows how to farm each one. It reads a sealed DefiLlama snapshot, scores every protocol that records no token with a model derived from the snapshot's own live-token market caps, and writes a static dashboard with a sortable, filterable board, a detail view per protocol and a farm plan per row.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
